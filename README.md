# 北宜高鐵，值得嗎？

反北宜高鐵議題網站。手機優先的捲動敘事單頁：俯視視角高鐵列車固定在畫面上，地景（南港城市 → 雪山 → 翡翠水庫 → 雪隧段 → 蘭陽平原）隨捲動後退，千元鈔從車尾狂噴，右上角燒錢碼表跟著捲動進度累計。

- 線上：<https://guanwei-cmd.github.io/hsr-yilan/>
- 部署：push 到 `main`，GitHub Pages 自動發布（約 1 分鐘）

## 檔案結構

| 路徑 | 內容 |
|---|---|
| `index.html` | 全站唯一檔案。CSS、JS、資料、canvas 繪圖全部內嵌，無 build step、無相依套件 |
| `img/` | 名錄肖像（`*.jpg` 長邊 480px、`*_s.jpg` 長邊 240px，皆已裁方形）與地理影像（`corridor.jpg` 走廊、`yilan_ortho.jpg` 站區） |
| `img/CREDITS.md` | 肖像與地理影像逐張出處與授權依據。**新增素材必須同步這份** |

改站直接編輯 `index.html`，本機 `python3 -m http.server` 開起來看即可。

## 撰寫與排版規範

以下與 [`techit-npp/taiwangogo-site`](https://github.com/techit-npp/taiwangogo-site) 的設計系統紀律同步（該站規範見其 `CLAUDE.md` 第 4 節）。

### 一、禁用破折號

**不得使用「——」。** 需要停頓改用句號分句，需要引出清單改用「：」。

這條同時是這個帳號所有專案的通則：破折號密集出現是 AI 生成文字最明顯的特徵之一。

### 二、斷行不切句

標題與金句只在標點後折行，不從子句中間斷開。

實作是 `index.html` 內的 `clauseWrap()`：把目標元素的**直接文字節點**依標點切段，每段包成 `<span class="nb">`，靠 `.nb{display:inline-block}` 讓每個子句成為一塊、整塊換行。元素子節點（`<em>`、`<br>`、既有的 `<span>`）不進入處理，段落正文不處理，交給自然換行。

```
斷點：，、。；：！？…・ 以及半形／全形空格
套用：main h1, main h2, main h3, .hero .sub, .dclead p,
      .tlgs, .tlgh b, .dchd b, .tksnark, .hzsay
```

動態產生的區塊（雙軌對照段落、名錄）建完之後可再呼叫一次 `window.clauseWrap()`。

**與 taiwangogo-site 的一處刻意差異**：本站多一段「純標點併回前一塊」的處理。原版遇到 `…<span class="nb">近 6,000 億</span>。往下滑…` 這種結構時，會把緊接在元素後面的單一「。」切成獨立的 `.nb`，可能讓句號落單成行。本站改為併入前一塊，輸出 `近 6,000 億。`。

### 三、字體

本站與 taiwangogo-site 的差異是**刻意的設計決定**，不同步：

| | taiwangogo-site | 本站 |
|---|---|---|
| 內文 | `'Noto Sans TC', sans-serif` | `--sans`：`PingFang TC`, `Noto Sans TC`, `Microsoft JhengHei`, `system-ui` |
| 標題 | 同內文 | `Noto Serif TC`（明體標題是批判文宣風定稿的一部分） |
| 數字 | 同內文 | `--mono`＋`font-variant-numeric: tabular-nums` |
| 字級 | 四級制固定值（`--fs-l/m/base/xs`） | `clamp()` 逐元素響應 |

共同遵守：`line-height: 1.75`、`-webkit-font-smoothing: antialiased`。

字級不採四級制，是因為本站是單頁捲動敘事，字級隨敘事節奏變化（hero 特大、卡片標題中、註解小），套固定四級會失去節奏。要改成四級制等於重做視覺，不是同步規範。

### 四、視覺語言（批判文宣風，2026-07-27 定稿）

黑紅白灰抗議公文系。黑色 HUD 帳務列＋紅色碼表、血紅 `#B3261E`、明體標題、方角卷宗卡（黑案由籤＋紅查核章＋硬陰影）、灰階水墨地景＋深黑軌道。只有鈔票（藍）、印章（紅）、列車橘帶有顏色。

調性：不可愛、要嘲諷心酸，鈔票要奔放。

**新增區塊一律用卷宗卡承載。** 文字不可以直接壓在頁面背景上，因為 canvas 地景捲到隧道段會轉全暗，深色文字會消失。

## 互動元件

三個元件的資訊結構參考報導者 [`orangutan-monorepo`](https://github.com/twreporter/orangutan-monorepo)（MIT），但**不引入套件**，以本站設計語言重寫。套件是 React ＋ styled-components，bundle 270KB 起跳，且會帶進報導者自己的視覺語言。

| 元件 | 位置 | 說明 |
|---|---|---|
| 走廊飛越 | `.fly` / `.flyview` / `.flymk` | 官方正射影像沿真實地標路徑推進。地標由經緯度換算座標，不繪製路線線形 |
| 兩層時間軸 | `.tl` / `.tlg` / `.trow` | group（階段）／unit（事件）兩層。每組有期間、標題、件數與一行階段摘要 |
| 雙軌對照 | `.dcsec` / `.dcstage` / `.dcstep` | 比較盤 `position:sticky` 釘在 HUD 下方，五段文字捲到定位切換。用 IntersectionObserver 帶狀取樣 |
| 橫向對照 | `.hz` / `.hzpin` / `.hzstrip` | 釘住後由垂直捲動換算水平位移，加分段 easing 讓每張卡對位時停留 60% 行程 |
| 分層名錄 | `#qwallA` / `#qwallB` | 曾任中央政務首長 5 人（大 chip，頭像＋短職稱）／學者與實務專業者 10 人（小 chip，頭像） |

### 效能與可及性慣例

- **不掛 scroll listener。** canvas 用 rAF 取樣捲動進度，DOM 用 IntersectionObserver
- **HUD 高度不要寫死。** 啟動時量測寫進 `--hud-h`（實測約 75px，隨字級與換行變動），所有 sticky 定位都吃這個變數
- **JS 失效要有保險。** 有 `<noscript>` 降級樣式，另有 3 秒逾時強制補上 `.in`
- 對比至少 WCAG AA（`--faint` 為 `#6B675E`，勿改回 `#8A867C`）；觸控目標 ≥46px
- 粒子上限 110
- `prefers-reduced-motion` 一律降級：卡片 reveal、數字滾動、雙軌淡入全部關掉
- 捲動驅動的元件要保留可點擊的替代操作（雙軌對照的 chip 同時是進度指示與跳段按鈕）

## 內容紀律

這是問責型網站，**每個數字都要能回推到出處**。

- **不捏造引言。** 名錄每則都是逐字原文，附原始連結、日期，並標明「具名投書」或「媒體報導」。查不到逐字原文的一律不列
- **宜蘭高鐵政策查核頁已全面停止引用。** 2026-08-07 逐句回溯後，賀陳旦、陳建宇、張景森等則在任何原文中都找不到，屬改寫或捏造。2026-08-20 起連大事紀與總帳組成也不再採用，全部改由監察院調查報告、環評報告書定稿本與各原始報導逐項替換；頁尾設有「不採用的來源」段落公開說明。**不要再把它加回任何出處清單。**
- **算不了就不算。** 查不到可引用出處的數字（例：站到家的接駁分鐘數）不列推估值
- **轉乘的計算判準（2026-08-21 定案，這是全站最易被攻擊處，不要改動）**：只計入確定會發生的換乘，分鐘數查不到出處就不估。
  - 宜蘭端：高鐵只設一站，到頭城、礁溪、羅東、蘇澳新都必須換臺鐵，圖 7 已加計 10 分鐘；直鐵行駛臺鐵路線直接停既有五站，監察院調查意見原文稱「到站即到家的優勢」，故不加計
  - 西部端：走直鐵必須在南港換乘（高鐵 1435mm 標準軌獨立專用線 vs 臺鐵 1067mm，無法直通），據實標示但不估分鐘數；走高鐵能否由西部直通，監院載明營運模式「迄未確認」，同樣不估
  - 那 10 分鐘標示為「陳訴人提供」，是**對高鐵有利的假設**：運研所指出宜蘭站轉乘若超過 25 分鐘，約 50% 北部往返花東旅次會改搭全程臺鐵
  - 對自己不利的那一格要主動補上。主張是「兩案沒被同一個基準比過」，自己就得先做到同一個基準
- **口徑統一為公民總帳 5,837 億**，三項組成各有官方文件可回推，**不要改回 5,965／3,650**：
  - 工程 3,521.75 億＝行政院 2026.07.23 核定
  - 30 年營運 1,735.32 億＝環評報告書定稿本表 9.1.3-15、9.1.3-20（監察院引述）
  - 臺鐵 30 年票收短收 580 億＝臺灣鐵路產業工會依臺鐵公司 7/22 評估推估，逐字載於監察院報告
  - 3,650 億雖出現在監院報告案由，但標示為「據訴」（陳訴人所述），不採用
  - 敘事上仍可說「近 6,000 億」，但數字一律寫 5,837
- **監察院 115 交調 0004 調查報告不標日期。** 報告全文查無任何審議或公布日期，只載明 115.02.09 詢問各機關後「已調查竣事」。最早公開報導為中央社 2026.05.12、聯合報 2026.05.13。站上只標案號
- **報告全文未使用「違失」一詞。** 正式用語是「調查意見」，處理辦法為「函請行政院督同相關部會參處」，不是糾正案。五項調查意見的逐字標題見 index.html 出處摺疊區；注意是「未先**提出**可行性研究」不是「未先完成」
- **30 年營運成本兩案同源**：均出自 114 年環評報告書（定稿本）表 9.1.3-15、9.1.3-20，監察院引述為高鐵 173,532.3 百萬元、直鐵 17,017.1 百萬元。不可一欄標監察院、一欄標環評，會讀成基準不同
- **圖 7 的行車時間資料來源標示「陳訴人提供」**，引用時必須寫明，不可說成監察院或鐵道局估算
- **自償率 6.8% 是鐵道局自陳**，不是公民試算
- **不能寫「蔡時代沒在動」。** 高鐵取代直鐵的轉向發生在前一任政府任內（2019 起），2024 之後才進入衝刺。時間軸第一組已明確標示這件事
- 陳琬惠是民眾黨，不能算時代力量發言者
- 翡翠水庫集水區是 2006 直鐵版本被否決的原因，高鐵路線官方稱已避開，水源論點不能直接套到高鐵

### 肖像

三類來源，逐張記於 `img/CREDITS.md`：公有領域、政府網站資料開放宣告（GWOIA，須註明出處）、機構官網公開簡介照（依著作權法 §52、§65 之引用合理使用，非營利、縮圖、與逐字引言及原文連結並列，權利人異議即移除）。

商業媒體新聞照不使用。查無可用肖像者以姓名首字色塊呈現（目前為濮大威、張智欽）。

### 地理影像

正射影像取自內政部國土測繪中心「國土測繪圖資服務雲」WMTS，**只用官方「免申請服務介接說明表」列出的圖層**（正射影像為第 11 項 `PHOTO2`）。分年正射影像圖層（`PHOTO2015` 至 `PHOTO2025`）技術上抓得到，但不在免申請清單內，屬須申請之服務，本站不採用。

圖磚抓下來後自行託管，不即時介接政府伺服器。使用時註明出處（政府資料開放授權條款第 1 版）。

**不畫路線、不畫範圍。** 走廊圖上的地標由實際經緯度換算，位置可驗證；但本站未取得可公開的高鐵線形與特定區界線圖資，因此不繪製路線，420 公頃紅框也只呈現面積大小，並在頁面上明確標示不是公告範圍。
